⚙️ Setup Backend

The frontend is hosted here, but you need to run the backend API:

pip install -r requirements.txt uvicorn app.main:app --reload

Then configure the API endpoint in settings.

🔧 Configuration

For Local Testing:

# Copy and configure environment cp .env.example .env # Edit .env with your API keys: # GROQ_API_KEY=your_key # GOOGLE_API_KEY=your_key (optional) # OPENAI_API_KEY=your_key (optional)

API Endpoint Configuration:

Edit static/js/main.js

// Default (same host): const API_ENDPOINT = "/triage"; // Production: const API_ENDPOINT = "https://api.your-domain.com/triage";
